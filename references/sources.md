## 1. 中文社区（密度最高，但要会筛）

### 1.1 图拉丁吧（贴吧）

- **价值**：垃圾佬密度最高的地方。矿卡识别、魔改卡、老平台捡漏的一手经验都在这里。
- **怎么用**：搜具体型号 + 问题词（`6500XT 矿` `B550 点不亮`），不要看"避坑大全"这种合集帖——那种帖子 80% 是转述。
- **可信度**：**高，但只有带图的帖子**。带实拍图 + 带具体数字（温度、跑分、SN）的帖子可信；纯文字的"我劝你别买"没有信息量。
- **边界**：图吧有大量"乐子帖"和同行互黑，**看到"某商家是骗子"这类指控时不要直接采信**。

### 1.2 NGA 硬件区

- **价值**：中高端玩家集中，**翻车案例库**做得比贴吧系统。有专门的"中低端电源信息及翻车案例整合"这类长贴。
- **怎么用**：查某个具体型号的**通病**（"某型号电源炸机""某主板内存兼容问题"）。
- **可信度**：**高**，因为 NGA 的帖子有楼层上下文，能被反驳。
- **边界**：偏中高端，2000 元档的低价件讨论少。

### 1.3 Chiphell

- **价值**：高端/折腾向，拆解和用料分析质量高。
- **边界**：**和 2000 元档基本无关**，别在这里找低价件。

### 1.4 什么值得买（SMZDM）

- **价值**：**踩坑帖的聚合质量意外地高**。搜索"闲鱼 装机 踩坑"能翻到按月整理的案例汇总，而且带原始帖子链接。
- **怎么用**：看"XX月闲鱼踩坑帖汇总"这类文章，快速了解**当前流行什么骗术**。
- **可信度**：**中**。它是二手转述，但转述时会附原帖链接，可以回溯。
- **边界**：部分文章带推广链接，看结论不看推荐。

### 1.5 Stage1st / 其他小论坛

- **价值**：偶有高质量的"卖卡被坑"实录（比如被外挂秒拍、被同行恶意举报）。
- **边界**：样本少，只能当个案看。

## 2. 英文社区（方法论更系统）

### 2.1 r/hardwareswap（最有价值）

**它的规则本身就是一套防骗方法论**，比大部分中文攻略系统：

| 机制 | 具体做法 | 可迁移到闲鱼吗 |
|---|---|---|
| **强制时间戳** | 卖家必须拍一张写有「当天日期 + 用户名」的纸条放在商品旁 | ✅ **强烈建议**。闲鱼没有这个要求，但你可以**主动要求** |
| **视频时间戳** | 超过 $400 的商品要求**视频**里也带时间戳（因为 PS 图片太容易） | ✅ 高价件必须要求 |
| **只认 G&S 付款** | 非本地交易只允许 PayPal Goods & Services（有买家保护），Friends & Family 一律视为诈骗信号 | ✅ 对应闲鱼：**只走平台内交易**，任何"加微信转账""私下打款"直接放弃 |
| **信誉系统** | 按成交次数分级，低信誉卖家只能用 G&S | 参考闲鱼的好评率 + 卖出件数，但**不作为唯一判据**（见 SKILL.md 原则 5） |

**关键洞察（来自 2026-06 的官方警示）**：
> "Fake Timestamps: AI/Photoshopped timestamps for high-value items. Always verify timestamps and request video timestamps for items over $400."

→ **时间戳也能 PS 了。** 所以对高价件，"纸条照片"不够，要**视频**。

### 2.2 r/HardwareSwapUK 的防骗 FAQ

这份 FAQ 把骗术按"买家视角 / 卖家视角"分列，是目前见过结构最清晰的：

**买家要警惕的**：
- 价格明显低于其他挂单（用 eBay **已售出** 列表比价，不是在售价）
- 卖家催你走无保护付款方式
- 卖家对简单问题给超长回答（**过度分享是掩饰信号**）
- 卖家的出售理由不合理（"忘了退货所以卖"这类）

**卖家要警惕的**：
- 买家发假的付款截图（假银行 App / 假 PayPal 邮件）
- 买家"转错金额"要求退款
- 买家收到货后发起恶意拒付

**可迁移的一条**：
> "Videos in particular are harder to fake than photos."
> → **要视频，不要图。** 这条在闲鱼同样成立，而且比"要截图"更难被糊弄。

### 2.3 eBay 的已售出列表（比价神器）

- **怎么用**：搜型号 → 筛选 **Sold + Completed**（已售出 + 已完成）。这才是**真实成交价**，不是卖家的期望价。
- **为什么重要**：闲鱼没有"已售出价格"这个公开数据，所以 eBay 的已售出价是**最接近真实成交价的公开参考**。
- **边界**：海外价格 + 关税 + 区域差，只能当**相对参考**（比如判断"这张卡是不是低得不正常"），不能直接换算成人民币。

## 3. 平台规则与维权（最硬，但最多人不知道）

> 这一节全部来自**闲鱼官方协议原文**，不是攻略转述。

### 3.1 ⚠️ 最关键的一条：受理期限

> 《闲鱼社区交易争议处理规范》第二十一条：
> "**在确认收货前**或在《闲鱼交易超时说明》超时打款的时限内提出退款申请，闲鱼进行受理。
> **特别风险提示**：个人物品的交易并非商品经营行为……**一旦交易成功，之后产生的纠纷争议闲鱼将不予受理。**"

**这是整份规则里最重要的一句。** 翻译成人话：

- **确认收货 = 平台不再管你。**
- 所以：**所有测试必须在点「确认收货」之前跑完。** 这是 `pc-parts.md` §13 验货流程存在的全部理由。
- 已经确认收货后仍有 **15 天**的「售后维权」入口，但**难度高很多**（不再是平台常规通道）。

### 3.2 平台认定的四类问题（决定你能不能用哪条举证路径）

| 术语 | 官方定义（原文） | 你的举证要求 |
|---|---|---|
| **表面不一致** | 凭肉眼即可判断的破损、少件、空包 | **开箱视频**即可，举证责任在卖方（第33条） |
| **描述不符** | 与卖方描述不相符，或卖方未披露瑕疵 | 肉眼可识别 → 图片/视频；**肉眼不可识别 → 需要质检证据**（第36条） |
| **质量问题** | 违反法律法规或平台规范 | 同上，功能性故障属"肉眼不可识别" |
| **瑕疵异常** | 外观破损、功能异常、**配件部件更换或缺失** | 卖方有**主动披露义务**（第38条） |

**对你的实操意义**：

- **"功能有问题"属于「肉眼不可识别」** → 你必须提供**质检证据**，光拍照片不够。这就是为什么 `pc-parts.md` 要求你到手先跑 CDI / FurMark / TM5——**那些截图不只是给你自己看的，是维权证据**。
- **"配件被换过"属于「瑕疵异常」** → 卖方有披露义务。如果他没写"换过散热/换过风扇"，你拆开发现换了，**这条能赢**。

### 3.3 小法庭机制（17 人投票，9 票赢）

**流程**（来自多个实操记录交叉验证）：
1. 卖家拒绝退款 → 你点「申请平台介入」
2. 进入**闲鱼小法庭**：17 位随机陪审员（信用良好的普通用户）投票，**9 票即胜**
3. **前 24 小时**：双方举证。发起方先发言 1 次，之后双方各可发言 5 次
4. **后 24 小时**：评审员投票
5. **票差小于 4 票可以申诉**

**赢了立刻到账；输了必须接受退货。**

**举证格式（这条最实用）**：
> 订单号 + 卖家描述原文 + 实物问题 + 证据
> **只讲事实，不带脏话，不骂人。**

**不要做的事**：
- ❌ 说"这个人是骗子" → 改成客观描述"买家签收后无客观故障，主动要求减钱，属于到手刀"
- ❌ 情绪化长篇 → 评审员看不完
- ❌ 分条不清 → 用编号列表

### 3.4 验货宝：它到底验什么，不验什么

**验什么**（协议 5.7.1，针对手机/数码类）：
- 商品主件的**基本信息**
- **设备功能**
- **拆修历史**

**不验什么**（这是最重要的部分）：
- ❌ 外观划痕、磕碰、掉漆
- ❌ 屏幕老化、进灰、亮点坏点
- ❌ 按键弹性
- ❌ 信号强弱
- ❌ 声音大小 / 杂音
- ❌ 设备检测结果存在**确定性的浸液、维修**
- ❌ 服务商验货时未出现、你收货后出现的功能异常

**最关键的一条（协议 5.5）**：
> "因商品交易前您与卖方沟通中的信息服务商并无法知悉，因此**买卖双方私下聊天内容内的承诺，不在服务商验货服务检验范围内。**第三方服务商只对商品符合相应工艺特征、材质是否相符，以及**卖方在商品详情中宣称的商品瑕疵信息**履行鉴定义务。"

→ **卖家在私聊里承诺的，验货宝一概不管。** 所以：**任何关键承诺，都要让他在商品描述里写一遍**，或者截图留证。

**⚠️ 另一个反常识点**：
> 某踩坑帖原话："验货宝只能检测硬件问题，**不能判断是否为矿卡**。"

→ **验货宝 ≠ 矿卡检测。** 别把它当成矿卡兜底。

**费用与时限**（协议原文）：
- 验货结果出具后 **48 小时内**必须决定"确认购买"或拒绝，否则视为拒绝、自动关单
- **验货服务费由买方承担**（即使你拒绝购买也不退，除非判定卖家货不对板）
- 确认购买后**不支持退换货**
- 收到货后 **5 日内**可申请「验错包赔」，走二次验货

### 3.5 维权路径阶梯（按成本从低到高）

```
① 未确认收货 → 申请退款（最优，平台常规通道）
      ↓ 卖家拒绝
② 申请平台介入 → 小法庭（17人投票，9票胜）
      ↓ 输了 / 票差 <4
③ 申诉（票差小于 4 票时可用）
      ↓
④ 确认收货后 15 天内 → 订单页「售后维权」入口
      ↓
⑤ 闲鱼人工客服 9510222 → 申请小二人工复核
      ↓
⑥ 12315 投诉
      ↓
⑦ 人民法院在线服务小程序 → 线上起诉（金额大时）
```

**每一步的成本**：
| 阶段 | 时间成本 | 成功率 |
|---|---|---|
| ① 退款 | 1–3 天 | 高（证据齐） |
| ② 小法庭 | 2 天（24h 举证 + 24h 投票） | 看证据质量 |
| ④ 售后维权 | 数天 | 中 |
| ⑤ 人工客服 | 数天 | 低-中 |
| ⑥ 12315 | 1–2 周 | 看金额 |
| ⑦ 起诉 | 数周-数月 | 高但成本高 |

## 4. 厂商官方口径（唯一能"一票否决"的源）

### 4.1 驱动/支持生命周期（必查）

| 厂商 | 查什么 | 地址/方式 |
|---|---|---|
| **NVIDIA** | Maxwell / Pascal / Volta 已 EOL（2025-10 起只剩安全更新） | 官方公告 `nvidia.custhelp.com` 搜 "Support Plan for Maxwell, Pascal, and Volta" |
| **AMD** | Radeon 老卡驱动状态 | AMD 官网 drivers 页的 "Legacy" 分区 |
| **Intel** | Arc / 核显驱动支持 | Intel 官网下载中心 |

> 这条在 `pc-parts.md` §16 已展开。**这是唯一能"一句话否定一张卡"的源**——性能再好，驱动 EOL 就是不能用。

### 4.2 主板 CPU 支持列表

- **微星**：官网 → 产品页 → Support → CPU Support（会标 BIOS 版本要求）
- **华硕**：产品页 → Tech Spec → CPU Support List
- **技嘉**：产品页 → Support → CPU Support List

> **查这个能避免"买了板子点不亮 U"**。B350 上 5000 系、B450 上 5000 系，都要看具体 BIOS 版本。

### 4.3 SN 保修查询

| 品牌 | 入口 |
|---|---|
| 华硕 | 官网 → 服务支持 → 保修查询 |
| 微星 | 官网 → 会员中心 → 产品注册/保修查询 |
| 技嘉 | 官网 → 支持 → 保修查询 |
| 西数 / 铠侠 / 三星 | 官网 → 支持 → 保修状态查询 |
| 影驰 / 七彩虹 / 铭瑄 | 官网或微信公众号 |

**用法**：让卖家拍 SN 照片，你自己去官网查。**SN 查不到 = 这张卡来路不明**（可能是工包、可能是翻新、可能 SN 是贴的）。

### 4.4 官方规格页（证伪"同名不同质"）

见 `SKILL.md` 阶段 1.2 的「官网关键词命中次数」法。**这是拆解"同名不同质"最快的工具。**

## 5. 行情数据源（判断"该不该现在买"）

> 这一节解决 `SKILL.md` 原则 6 说的问题：**AI 的知识库会过期，行情是活的。**

### 5.1 VRAMGlass（最硬，直接抓闲鱼挂单）

**vramglass.com** —— 显卡大盘指数，**每 6 小时更新**，数据源就是**闲鱼挂单中位价**。

- 有「入门 / 主力 / 旗舰」三档指数，能看出涨跌来自哪个价位段
- 有 24 小时 / 7 天 / 30 天涨跌幅
- 明确标注："这些是卖家的**报价**，不是最终**成交价**"

**怎么用**：
- 判断**趋势**（现在该买还是等）：看 30 天涨跌幅
- **不能**用它定单张卡的价格（它是中位价，不是你的目标卡）

### 5.2 5iVideo 显价（按芯片聚合，有二手区间）

**5ivideo.com** —— 覆盖 37 款主流显卡，每个型号给三档价格：

- **大陆官方首发价**
- **近期全新 低 / 高 / 中位**
- **近期二手 低 / 高 / 中位**

**这是最接近"这个型号二手应该多少钱"的公开数据。** 而且明确写了"同芯片不同品牌与散热规格合并统计"。

### 5.3 老显卡库（laoxianka.com）

专做老卡：7318 个型号、二手参考价、矿卡/通病标注、本地跑 AI 的适配信息。

**适合**：捡老卡、查"这张卡有什么通病"。

### 5.4 慢慢买（历史价格曲线）

**manmanbuy.com** —— 主要做**新品**历史价，能看"这个价格是不是真降价"。

**边界**：**二手数据弱**。它的强项是新品比价和历史最低价，不是二手行情。

### 5.5 eBay 已售出（真实成交价，海外参考）

见 §2.3。**闲鱼没有公开成交价，eBay 的 Sold 列表是最接近的替代品。**

### 5.6 B站月度行情视频

搜「XX年XX月 二手显卡行情」，有 UP 主按月更新（如「清诚实验室poi」连续更新了两年多）。

**价值**：**有实测、有走势判断、有推荐**。
**边界**：视频有时效性，**看完要核对当天的实际挂单**（这正是 `SKILL.md` 原则 6 的意思）。

## 6. 骗术模式库（按"造假层次"分类）

> 这一节把各来源的骗术按**造假的技术层次**归类——因为**层次决定你怎么验**。

### 6.1 第一层：物理伪装（洗、换、贴）

| 手法 | 怎么做的 | 怎么验 |
|---|---|---|
| **水洗** | 洗板水去灰去氧化 | **全卡贼干净但某个角落很脏** = 没洗干净 → pass |
| **换散热/风扇** | 换全新风扇和硅脂，看起来像新的 | 风扇型号对不对？拆开看硅脂新旧 |
| **换标签/贴纸** | 复刻原厂标签、重打 SN | SN 官网查；标签印刷质量 |
| **打磨丝印** | 把颗粒丝印磨掉重印 | 丝印边缘有没有打磨痕迹（放大看） |
| **换电容** | 把发黄的电容换掉，掩盖高温史 | 焊点是否原厂（新焊点颜色不同） |

**判据优先级**：**核心/显存区电容焊脚发黄**（化学反应，洗板水/牙刷/超声波都去不掉）> 其他一切外观线索。

### 6.2 第二层：软件伪装（刷 BIOS）⚠️ 2026 年最新、最难防

**这是今年最重要的一条**，来自 2026-09 的实测报道：

> "这个新骗局的狠处在于造假搬进了软件层：**注册表、魔改 VBIOS、定制驱动，三重手段让一张 4060 在系统和 GPU-Z 里都显示为 4070**，专坑'半懂不懂'的买家。"

**为什么这摧毁了"看截图"这条路**：
> "你按攻略管住自己'先看截图再下单'，可 GPU-Z 的数据恰恰从 BIOS 里读——**当 BIOS 本身就是刷出来的，截图和卖家自拍照一样，只是他没成本的表演。**"

**三个"不认字体"的硬指标**（原文建议）：
1. **现场跑 3DMark** —— 分数和型号的匹配度刷不掉
2. **烤机 15 分钟** —— 核心温度超 85℃、风扇异响或黑屏的，散热供电必有暗伤
3. **显存专项检测** —— 报错单元直接否决

**"亮机 ≠ 没病"的铁证案例**（罗马尼亚那张技嘉 4090）：
> 亮机、能进游戏，但 **OCCT 显存检测 15 秒报了 470 多万次错误**，24GB 里 1.5GB 已永久失效。

→ **必须跑显存检测（OCCT / MemTest_vulkan），不是跑个 FurMark 就算完。**

**刷 BIOS 的工具链（知道原理才能防）**：
- N 卡：**NVFlash**（Windows 下管理员运行即可）
- A 卡：**AMD/ATI Flash**（新版有图形界面）
- 经典操作：**GTS450 刷成 1050Ti**（192 个流处理器冒充 768 个）、RX460 刷 RX560 开核、RX5700 刷 5700XT

**怎么识破刷 BIOS**：
| 查什么 | 在哪看 | 判据 |
|---|---|---|
| **流处理器数** | GPU-Z | 和官方规格对不上 → 假卡 |
| **核心代号** | GPU-Z | 如 GF116（GTS450）冒充 GP107（1050Ti） |
| **制程** | GPU-Z | 40nm 冒充 14nm |
| **BIOS 日期** | GPU-Z | 早于显卡发布日半年以上 → 可疑 |
| **BIOS 关键词** | GPU-Z | 含 `MINER` / `ETH` / `LHR` → 高度可疑 |
| **硬件 ID** | 设备管理器 | 与标称型号不一致 → 假卡 |
| **3DMark 分数** | 现场跑 | 和型号匹配度对不上 → 假卡 |

### 6.3 第三层：身份伪装（卖家/买家都可能假）

**卖家侧**：
- "女生自用，买了新电脑出旧卡" —— 矿卡贩子最常用的话术
- "网吧倒闭，机器整体出" —— 网吧机器使用强度高
- "从没打过游戏，就是跑跑计算" —— 90% 在掩盖挖矿史
- "包装配件齐全，支持验货" —— **包装可能后配，验货宝不判断矿卡**
- **"换 5070 了闲置出"** —— 涨价期 JS 冒充个人已是主流身份骗术，这句话本身就该触发回溯验证

**买家侧（卖东西的人也要防）**：
- 假付款截图（假银行 App / 假 PayPal 邮件）
- "转错金额"要求退款
- 到手刀（收货后编理由砍价）
- 用外挂秒拍，然后同行恶意举报

### 6.4 第四层：交易环节（平台也保不住）

**调包**（最狠）：
> 真实案例："拆机下来的 5800X + B550M-PLUS WiFi + 32G 内存整套寄出，**主板在半路被人动了手脚**。"
> 教训："验货证据链断在快递箱里，平台只处理钱、处理不了芯。"

→ **开箱视频必须一镜到底，从快递面单开始拍。** 这是对抗调包的唯一证据链。

**毁单**（涨价期高发）：
> 谈好价拍下、加价协商一致，买家把其余配件全部下单发出后，**卖家晚上单方面关闭订单、拉黑走人**。

→ **交易顺序要反过来：先验卡收货，再配其余件。** 别让全套沉没成本先替卖家把违约的账结清。

**赌卡盲盒**（期望值随行情恶化）：
> "卖家每多一条出路——单卖、卖料、卖核心、卖给维修号做视频——就多一分把'还能亮的卡'挑出去、只把砖头留进盲盒的动力。**行情每涨一档，盲盒的期望值就薄一层。**"

→ 涨价期**不要赌卡**。
