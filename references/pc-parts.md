# 电脑配件品类手册（DIY 装机 / 二手比价）

> **可选品类手册。只有任务确实是"电脑配件 / DIY 装机"时才读本文件。**
> 通用流程（白名单构建、同名拆分、翻页陷阱、详情页核验、批量收藏）在 `SKILL.md`，本文件只放**电脑品类专属**的东西。
> 数据基准：2026-11 实测（闲鱼 + 拼多多 + 京东自营 + B站装机视频交叉核对）。**价格会漂，用前重抓。**

## 0. 一页结论

**⚠️ 顺序纪律（最重要）：先用近期 B站实测视频定主方案，再谈省钱。**
硬件行情和 SKU 版本迭代很快，**知识库天生会过时**。所以：**近期（3 个月内）装机/拆解视频 → 主方案 → 三档预算**。
矿卡（RX470-580 / VEGA56-64 / 5600XT-5700 / GTX10系 / RTX30系）与魔改卡（P106 / CMP 30HX-90HX / V100 / 移动端魔改）**默认全部作废**，只在用户明确要求压预算时作为**单独成段的替补**出现。见 §17。

**装机天然分两组，混着比价必错：**

| 组别 | 件 | 买法 | 理由 |
|---|---|---|---|
| 二手组 | CPU / 主板 / 内存 / 显卡 / 固态 | 闲鱼二手 | 折价大、失效后果可控（不亮而已） |
| 全新组 | **电源 / 机箱 / 散热器** | 拼多多/京东全新 | 电源是唯一「坏一件烧全机」的件；散热风扇轴承与机箱结构件二手无质保不值 |

**卖家身份不是风险变量。** 配件是标准件，商家往往比个人**更**能提供测试数据与退换：有备货、有测试台、有售后流程。只有**一体化的品牌整机 / 手机 / 品牌笔记本**才值得专门筛个人卖家（因为商家会拆件翻新、拼装）。
→ 详见 SKILL.md「原则 5」。

**矿卡的小 nuance（用户实测观点）**：个人卖家的卡本身也可能是二手矿卡转手，到手就是三手 —— 所以「个人 vs 商家」在矿卡上基本被抹平。**真正能降风险的是件上的物理证据**（见 §4）。

## 3. 证据分级（唯一靠谱的风险变量）

给每条挂单打级，**L2 及以下不进推荐**：

| 级 | 内容 | 例 |
|---|---|---|
| **L0 硬数据** | 可验证的数字 | 「甜甜圈占用 99%、温度 68℃」「健康度 88%、通电 1200h、写入 12TB、0E=0」「GPU-Z 截图」「SN 官网可查」「鲁大师 18.7 万」 |
| **L1 承诺** | 有兜底的条款 | 描述不符包邮退 / 只换不修 / 质保一年有问题包换 / **闲鱼验货宝（先验后买）** / 3 天无理由 |
| **L2 自述** | 只有形容词 | 「功能正常」「无暗病」「无拆修」「无矿」 |
| **L3 无** | 只有标题和价 | — |

**反直觉但实测成立的加分项：主动明示缺陷。** 写「缺背板，后面有磕碰」「有线网卡坏了，送 USB 网卡」「配的 3D 打印挡板」「没有 AM4 背板」的卖家，可信度**高于**满篇好话的。因为敢写瑕疵的人不怕你验。

## 4. 矿卡识别（判据来自 B站 BV1SztR6GEsz《…怎么远离矿卡》+ 通用实践）

### 4.1 时间线判据（最硬，先算这个再看别的）

显卡挖矿挖的是 **ETH**。**2022 年 9 月以太坊转 PoS 后，除非偷电否则挖矿血亏。**

→ **2022 年 9 月以后生产的卡，绝对没有矿**：

- N 卡 **RTX 40 系及以后**、A 卡 **RX 7000 系及以后** → 无矿
- A 卡 RX 6000 系里 **2022 年中旬出货的 6650XT 等「x50」后缀** → 基本满血，风险极低
- N 卡 30 系的 **LHR 锁算力版** → 挖矿亏本，GPU-Z 可看，无风险

### 4.2 四梯度风险分级

| 梯度 | 含义 | 型号范围 |
|---|---|---|
| **1 基本必矿** | 回本速度堪比光速，不必纠结矿不矿，就是买便宜 | AMD 14nm GCN 4G 以上大部分：RX 400 系（470D 级+）、500 系（560XT+）、VEGA 56/64、RX 5000 系（5600+） |
| **2 高概率** | 性价比高、风险也高，需多重验证 | N 卡 30 系（3080）、20 系（2060+）、16 系（1660+）、10 系（1060 6G+）；A 卡 RX 6000 系 6700+（除 6900XT）、R9 200/300 系（270/370+）、Fury/Fury X、7000 系（7850+） |
| **3 小概率** | 小白可买，问题不大 | N 卡 30 系 3060+（除 3080 与 LHR）、6900XT、Fury Nano |
| **4 不可能** | 挖矿回本遥遥无期，没人拿它挖 | 其余型号 + 新卡 + 特殊型号 |

> 老卡（第 1/2 梯度里的古董）**矿不矿已无意义**——不是矿也未必活得久，直接看物理状态。

### 4.3 四个识别动作（前三个都白搭）

| 动作 | 有效性 | 原因 |
|---|---|---|
| 看灰多不多 | ❌ | 贩子用洗板水就能搞定 |
| 看硅脂/是否拆开 | ❌ | 可重涂 |
| 看挡板锈迹 | ❌ | 可洗 |
| **看核心/显存区的电容与焊脚是否发黄（「大汗脚」）** | ✅ **宝藏方法** | 长期高温氧化的**化学反应**，洗板水洗不掉、牙刷刷不掉、超声波震不掉，**没有造假空间**。发黄 = 一定跑过高负荷（不一定是矿，网吧卡也会），剩余寿命相对短。**买电容焊脚保持良好状态的卡准没错** |
| **看标签 SN / 型号** | ✅ | 非公款式但标签**既不写品牌、也不写具体系列**（如「烈焰战神/Turbo」）→ 公包/特供涡轮卡，出生就不是卖给个人用户的 → **pass** |
| **看是否水洗** | ✅ | 全卡贼干净、**只有某个小角落很脏** = 没洗干净的翻新卡 → 矿卡概率暴增 → **pass** |

### 4.4 二手卡必问四件套

1. **十分钟 FurMark/甜甜圈烤机截图**（要看到占用率 + 温度数值，不接受只写"温度正常"）
2. **GPU-Z 截图**（看核心/显存型号、BIOS、LHR 标识）
3. **SN 照片 + 官网保修查询结果**
4. 一句话直问：**「有没有矿过、有没有拆修、能不能发发货前烤机视频」**

## 5. 分件选型与避坑

### 5.1 电源 / 散热 / 机箱：买全新，不买二手

**电源**（判据见 §15，那节是本手册里最该逐条过的部分）
- 全新网红档：**驿晨宇玄武 500K 优化版**（额定 550W / 白牌）官旗 ¥139；**玄武 500 旗舰** ¥159（五年保 / 全纯铜线 / ATX3.1）
- 历史坑：老批次 500K 有「20AWG 线材标 18AWG」虚标争议，官方已改标识并把 12V MOS 升级到可持续 600W → **只认 V4.0 / 优化版**
- 判据：**「全新未拆封 + 三年质保 + 支持个人送保」三项齐**才是全新；45–75 元的全是二手拆机

**散热**
- 利民 **AX120 R SE**（四铜管单塔）京东自营 ¥68–75，pdd ~¥55–65；B站装机视频普遍用「四铜管塔式」（如九杀 GF92A）
- 「65W 的 U，四铜管闭着眼压」
- ⚠️ **装塔式散热必须确认主板带 AM4 原装背板** —— 二手板经常缺，缺了装不上（要么让卖家补，要么另买 ¥10–15）

**机箱**
- 百元 mATX 档；**必须选前面板网孔/开孔款**
- 反例实测（真实用户评价）：未知玩家 X100 全包围玻璃款「双烤 CPU 95℃ / 显卡 89℃，玩 3D 要开侧板」→ 闷罐
- 手提款注意显卡限长（X100 是 335mm）与散热器限高（162mm）

### 5.2 固态：只看「颗粒 + 健康度」，不信「TLC」三个字

同称 TLC，实测健康度可以是 **21% / 49% / 不公开**：

| 实测样本 | 价 | 真实数据 | 判断 |
|---|---|---|---|
| SK hynix BC501 256G | ¥150 | 健康度 **21%**，通电 6698h | 原厂颗粒也不行，排除 |
| 英特尔 760p 256G | ¥138 | 健康度 **49%**，通电 42580h，写入 88TB，0E=0 | 便宜但寿命用掉一半 |
| 西数 SN720 256G | ¥168 | **不公开**，只写「点击购买可查看」 | 规格最强但必须追问 |

**必查 CDI 四项：健康度 ≥85%、通电小时、累计写入量、0E（媒体错误）必须为 0。**

- 256G TLC 白名单（OEM 原厂盘性价比最高）：**三星 PM981 / PM981a**、**西数 SN720**（OEM 版 SN750，带 DRAM 缓存）、**铠侠 KXG60 / XG6**、英特尔 760p、SK hynix BC501
- **QLC 黑名单**：三星 QVO 系列、西数 SN350、英睿达 P3、金士顿 NV1/NV2
- 协议陷阱：「512G 固态」可能是 M.2 但 **SATA 协议**（速度差 4–5 倍）、也可能是 **mSATA / 2242**（装不进 2280 位）
- 2026 现实：NAND 涨价，**512G → 256G 是省预算的第一刀**（省 ~130；B站多个 2000 元方案都用 256G）

### 5.3 内存：要大厂颗粒，别被「标价单条」骗

- **大厂颗粒** = 三星 / SK 海力士 / 镁光（**英睿达 Crucial 是镁光子品牌**、科赋 KLEVV 用海力士）；威刚、金士顿多为自封大厂片，可接受
- **白片/自封风险**：光威、金百达、金芝、金泰克、枭鲸 —— 便宜但颗粒不保证
- 判据：要卖家拍**颗粒丝印照片**确认原厂丝印（不是打磨重印）
- ⚠️ **「8G×2 套装 ¥248」实测是单条标价**：描述小字写「标价单条！标价单条！」→ 实际 ¥496，比套装还贵。**只要标题写 8G×2，必看描述有没有「标价单条/一根价」**
- **双通道是游戏底线**：不要用 8G 单条替 8G×2（2026 年 3A 会爆内存，帧数掉 15%+；装机视频也专门强调「两个 8G 组双通道」）
- **主板只有 2 条内存槽 = 16G 插满**，以后升 32G 要整套换掉（DDR4 涨价周期里代价很大）

### 5.4 主板：故障率最高的件，优先全新或带保

- B站装机视频原话：「**主板是电脑里故障率最高的硬件，不推荐选二手**，万一遇到有暗病的，能给你折腾得要命，尽量去某多某宝找带有质保的店铺」
- 二手只买同时满足：**原装 IO 挡板 + AM4 背板 + BIOS 已刷到支持目标 CPU**（要 CPU-Z/BIOS 截图，别听他口头说「支持 1-5 代」）
- **同价优先 PCIe 4.0**：B550M 中端（铭瑄终结者 ¥230）与 B450M MORTAR MAX（¥235）几乎同价，但 B550 多一个 PCIe 4.0
- **B350 + 最新 BIOS 确实能上 Ryzen 5000**：微星官方 FAQ（faq-8676）列明 B350M MORTAR 自 **AGESA ComboAM4v2PI 1.2.0.7**（BIOS `7A37v1O6`）起支持；但
  - **PCIe 只有 3.0**（详见 §5.5）
  - **微星 BETA BIOS 是「单程票」**：实测 `7A37v1OB` 降回 `7A37v1K` 直接变砖，最后靠编程器救回 → 刷了就往前用，别试降级
  - 早期 BIOS 内存只到 2666/2667，最新 BIOS 才能跑 3200
- **「丐」的真实后果不是供电**：65W 的 3600/5600 用 4+2 相（哪怕 24 颗 MOS + 同款 RT8894 PWM）绰绰有余。丐在 **2 条内存槽 / 1 个 M.2 / 千兆网卡 / ALC662 / 无 Type-C**
- 二手主板常见暗坑：**3D 打印挡板凑合、没有 AM4 背板、板载网卡坏了送 USB 网卡** → 都会变成额外成本

### 5.5 显卡：先算 PCIe 通道宽度，再算价格

**这是最容易被忽略、影响最实的一条：**

| 卡 | 原生通道 | 跑在 PCIe 3.0 上 | 实测损失 |
|---|---|---|---|
| **6500XT / 6400** | PCIe **4.0 ×4** | 3.0 ×4（带宽直接砍半，本来就窄） | **5~10%**，爆显存更惨 |
| **RX6600** | PCIe 4.0 **×8** | 3.0 ×8（基数够大） | **≈0~2%，基本无感** |
| ×16 卡 | PCIe 4.0 ×16 | 3.0 ×16 | 可忽略 |

→ **主板只有 PCIe 3.0（B350/B450/A520）时，避开 ×4 卡**；6500XT 配 A520/B350 是双输，配 B550 才满血。
→ 反过来：在 3.0 平台上「加钱换 RX6600」同时拿到更强性能和更小 PCIe 损失。

### 5.6 CPU

- AM4：**R5 3600**（Zen2 6C12T，¥350–400）vs **R5 5600**（Zen3，¥599–640）：**5600 单核 +19%，网游帧数 +20~25%**
- 只上 3600 → B450/A520 足够；上 5600 → 必须确认主板 BIOS 版本
- 排除词见 §2；另注意卖家**型号下拉选错**（把 5600 选成「5600X」是常见错，两者价差 100+）→ 要他拍顶盖

### 5.7 整机路线（对照，通常不推荐）

- 闲鱼「i3-12100F + H610 + 6500XT」整机 ¥1999 价格能打，但**整机商拼装、配件不可追溯**
- **一体化的品牌整机/品牌笔记本才是适合专门找个人卖家的品类**；DIY 组装机不是

## 7. 必问话术（逐件照抄）

- **CPU**：拍**双通道读写 + 烤机温度**截图；散片是否原针无弯？顶盖照片确认型号（别被 5600/5600X 混了）
- **主板**：**BIOS 版本号**截图；原装 IO 挡板 / **AM4 背板** / SATA 线齐不齐？有无修焊痕迹？
- **内存**：确认是 **8G×2 两条**还是单条；拍**颗粒丝印**；要 AIDA64 读写图
- **固态**：**CrystalDiskInfo 截图**（健康度 / 通电小时 / 累计写入 / 0E=0）；确认 **2280 规格 + NVMe 协议**（不是 SATA 协议、不是 2242）
- **显卡**：十分钟**甜甜圈烤机截图（要温度数值）**+ GPU-Z + SN 照片 + 发货前烤机视频；直问「矿过没、拆修过没」
- **电源**：三项齐 —— 全新未拆封 / 三年质保 / 支持个人送保

## 9. 会带偏结论的假象清单

1. ❌ **用卖家身份/好评率当风险信号**。好评 96% + 5 年卖 1190 件 ≠ 坑；**件上没有 L0/L1 证据才是坑**。这条是被用户当场纠正过的。
2. ❌ **用中文外号搜**（`B350M 迫击炮` → 猫砂挂包钓台）。
3. ❌ **只读搜索卡片就下结论** —— 卡片标题常省略关键差异（协议、通道数、容量组合）。
4. ❌ **沿用上一轮的报价**做最终清单（挂单会售出/降价）。
5. ❌ **为「供电不丐」多花钱** —— 65W U 上零收益；钱该给 CPU 或显卡。
6. ❌ **相信「TLC」三个字** —— 同称 TLC 健康度能差 4 倍。
7. ❌ **把「全新」字样当全新** —— 20 元的"幽灵散热器"是**线材**。
8. ❌ 详情页字段抓取时不对位 —— 字段名（品/型/成/功）后**第 2 个文本行**才是值；且要先截断到「为你推荐」之前。
9. ❌ **只要形容词不要图**。卖家写「功能正常/健康度100%/烤机61度」都不算证据，**要他截图和视频**；反过来，**图里有数据就先读图，别浪费一轮去问**。
10. ❌ **把标称参数当已核实**。规格表里的「限高 135mm」在缩略图里只有 200px 宽，必须放大才能读清；读错一位数就会买错机箱/散热。
11. ❌ **机箱和散热分开选**。硬约束要串起来算（见 §10）：先机箱限高，再散热高度，再显卡长度，再风扇位尺寸。
12. ❌ **把型号名当规格**（「YG500W」实际是 600W；「550 Pro」实际功率未知）。**只读铭牌算式：12V × A。**
13. ❌ **用品牌名判断同系列不同版本**（YG500 / Pro / V3 架构差一个时代，价差只有 40 元）。**版本号决定一切，按版本查拆解。**
14. ❌ **只看性能不看驱动生命周期**（GTX TITAN X 12G 光栅仍强，但 NVIDIA Maxwell 自 2025-10 已 EOL）。推荐里必须单列「支持状态」。
15. ❌ **把 PCIe ×4 卡配 PCIe 3.0 主板**（RX6500XT 掉 5~10%）；反过来把 3.0 卡配 4.0 板也是零收益。
16. ❌ **默认就推矿卡/魔改卡**。这是**替补**，不是主方案；主方案永远以近期 B站实测为准。**只有用户明确说要压预算才出现，且必须单独成段、标风险、给验证动作。**

## 10. 硬约束优先序（选件顺序）

**机箱 CPU 限高 → 散热器高度 → 内存槽数 → 显卡长度 → 风扇位尺寸 → 电源规格**

实测踩坑：利民 AX120 R SE 高 **148mm**，九尾狐 U1 机箱 CPU 限高 **135mm** → **根本装不进**。先定机箱才能定散热。同理机箱后窗只有 **8cm** 风扇位时，买 12cm 风扇等于白买。

- **余量规则**：散热器高度距机箱限高**至少留 5mm**；只剩 3mm 属于公差博弈（主板铜柱 + 插座高度 + 散热器公差叠加），装上后先别盖侧板，量过再合。
- **显卡要算供电头**：限长是「含 6pin/8pin 接头」的总长度，不是卡本体。
- **散热还要看扣具**：塔式散热吃主板**原装 AM4 背板**，二手板常缺（要另买 ¥10–15，或让卖家补）。

## 11. 读图核验（本手册最重要的一节）

> **原则：先问「卖家给的图已经证实了什么」，剩下的缺口才是要问的。** 图里有数据的直接读，不用浪费一轮对话；读不出来的那一项才发问。

| 件 | 图里要证实 | 图里找不到 ＝ 必须问 |
|---|---|---|
| **主板** | **数内存槽**（衍生版差异：`-K`=2 槽 / `-E`=4 槽）、一体式 IO 挡板、**背面 AM4 背板是否在**（决定塔式散热能否装）、CPU 座针脚、有无补焊/飞线 | BIOS 版本、针脚特写、封码与剩余保修 |
| **CPU** | **OPN 编号验型号**（`100-000000031`=R5 3600，`100-000000022`=3600X）、针脚是否全满无弯、顶盖边缘胶是否开盖、生产周期（`1918SUT`=2019 年第 18 周） | 双通道读写读数、FPU 温度、发的是图中哪一颗 |
| **内存** | **两条标签是否同型号同批次**（不是两条凑的）、颗粒丝印、金手指有无氧化、**CPU-Z 截图里的测试平台是 Intel 还是 AMD** | AMD 平台能否跑标称频率、MemTest/TM5 结果 |
| **显卡** | **GPU-Z 与 FurMark 同屏**、烤机时长、核心温度、**热点温度**、S/N、原盒、背板螺丝/挡板锈迹、电容焊脚是否发黄 | 两张现货时是哪一张（**指定 S/N 收**） |
| **固态** | **厂商官方工具截图**（西数 Dashboard / 铠侠 SSD Utility / 三星 Magician）优先于第三方 CDI | **通电小时、累计写入量**（官方工具常不显示这两项） |
| **机箱** | **放大参数表**读 CPU 限高 / 显卡限长 / 风扇位尺寸 / 板材厚度 / 是否支持水冷 | 限高从主板面还是 CPU 顶面算起、前面板是否网孔、风扇位确切尺寸 |
| **电源** | 铭牌额定功率、+12V 输出、认证编号 | 5V/3.3V 是否独立 DC-DC、线材纯铜/铜包铝、**AC 线地线是否通外壳** |

**两条硬判据（别人不问，且没法造假）**

1. **GPU 热点温差判硅脂**：`热点 − 核心 < 15℃` 良好；`> 25~30℃` 说明硅脂干/接触不良。
   实测参考：核心 **61℃** / 热点 **74℃**，Δ = **13℃** → 良好。
2. **矿卡「大汗脚」**：看核心/显存区**电容与焊脚是否发黄**。洗板水、牙刷、超声波都去不掉（化学反应）。发黄 ≠ 一定矿（网吧卡也会），但剩余寿命短。

**副产物判据**

- **背板螺丝锈迹** → 环境潮湿 → 必须追加查焊脚发黄。
- **CDI 显示接口 UASP** → 这块盘是在 USB 硬盘盒里读的，不是插 M.2 槽；不影响盘本身，但要知道。
- **CPU-Z 的系统信息** → 看出卖家在什么平台上验的；**Intel 能跑 3200 不代表 AMD 内存控制器也能跑**。

## 12. 图片抓取的两个格式陷阱（工程细节）

1. **alicdn 缩略图后缀决定实际格式**：`...-xy_item.jpg_220x10000Q90.jpg_.webp` 这种 URL 返回的是 **WebP**，不是 JPEG。要去掉 `_220x10000Q90.jpg_.webp` 后缀拿原图。
2. **HEIC 上传的图**：用 `...-xy_item.heic_790x10000Q90.jpg_.webp` 可拿到 WebP 转码版；本地保存**必须按真实格式命名**（存成 `.webp` 再读），命名成 `.jpg` 会让读图工具报
   `extension declares image/jpeg, but the bytes use a different image format`。
3. 抓图脚本：`document.images` 过滤 `bao/uploaded`，剔掉 `naturalWidth < 200` 的图标，按去查询串的 URL 去重。
4. **缩略图里的参数表必须放大**：商品图的规格表常常只有 200px 宽，用 Pillow `crop + resize(6x, LANCZOS)` 才读得清限高/限长/风扇位。

## 13. 「已买之后」的验货流程（闲鱼确认收货窗口 7~10 天内跑完）

1. 只装 **CPU + 1 条内存 + 显卡** → 进 BIOS 看**版本**和**内存频率是否到位**
2. 插齐内存 → **TM5 3 圈 / MemTest86 一晚**，0 报错（内存是唯一「平时不响、关键时刻蓝屏」的件）
3. 装系统 → **CDI 核健康度 / 通电 / 写入 / 0E**，和卖家说的一致再确认
4. 显卡 **FurMark 20 分钟** → 核心 60±5℃、热点 < 85℃
5. CPU **AIDA64 单烤 FPU 10 分钟** → 四热管塔式下 75℃ 内
6. 装散热后**先别盖侧板**，量顶部到侧板距离 ≥3mm 再合盖
7. **全部跑完才点确认收货**

## 15. 电源怎么判（同系列跨版本差异 > 跨品牌差异）

### 15.1 两条铁律

**① 型号名 ≠ 额定功率，只认铭牌这一行算式**

```
12V 电流 × 12 = 实际 12V 输出能力
```

实测案例：**YG500W** 这个型号名带"500"，但 V3 版是 **12V 51A = 612W，标称 600W**；上一版是 12V 41.7A = 500W。**同一个型号名，两代差 100W。**

厂商常把数字当系列名用。看到「YG500W」「500K」「550 Pro」都别当功率读，**让卖家拍铭牌**，只看 12V 那行。

**② 同一系列跨价位/跨版本，用料差异可能大于跨品牌**

实测案例：同一家「远古装机侠」三个 SKU，架构完全不是一个档次：

| 型号 | 价 | 额定 | 认证 | 同步整流 | 继电器 | 主电容 | 质保 |
|---|---|---|---|---|---|---|---|
| YG500（初代） | — | 500W | 白牌 | ❌ | ❌ | — | — |
| **YG500 Pro** | ¥99 | 500W 级 | 白牌 | ❌ | ❌ | 270μF | — |
| **YG500W V3** | **¥139** | **600W** | **铜牌（实测银牌效率）** | ✅ | ✅ | **390μF 日系 105℃** | **5 年** |

**40 元差价买到的是：+100W、同步整流、继电器、日系主电容、5 年保。** 光看品牌名「都是远古装机侠」会完全误判。

### 15.2 铭牌能看什么 / 看不出什么

| 铭牌上能读 | 铭牌上看不出来（必须看拆解或问卖家） |
|---|---|
| 额定功率、12V/5V/3.3V 电流、ATX 规范版本、AC 输入范围、型号、SN | **有没有同步整流**、**有没有继电器**、主电容品牌容量、输出电容是固态还是液态、拓扑（双管正激 / LLC） |

**所以流程是：铭牌算功率 → 拆解视频判用料 → 两者都要。**

### 15.3 五个真正决定档次的用料点

| 项 | 有 = 好 | 没有 = 差 | 为什么 |
|---|---|---|---|
| **同步整流** | ✅ 用 MOS 管整流 | ❌ 肖特基二极管 | 肖特基有 0.2~0.3V 压降，按 12V 50A 算 = **10W 白白发热**。这是「认证铜牌、实测银牌」的原因 |
| **继电器 + NTC 并联** | ✅ | ❌ 只有 NTC | 上电靠 NTC 限流防烧保险，启动后继电器短路掉它 → 正常工作时这颗电阻上**零损耗零发热**。作者原话：「这个继电器只有高端电源或大功率的（800W/1000W）里面才有」 |
| **5V/3.3V 是否独立 DC-DC** | ✅ 独立降压芯片 | ❌ 磁放大 / 群组稳压 | DC-DC 在小电压轨的负载调整率和纹波上天生更好 |
| **主电容** | 日系 105℃ / 容量大 | 国产 85℃ / 容量小 | 高压母线蓄水池，容量和耐温直接决定寿命 |
| **输出电容** | 固态（低 ESR） | 全液态电解 | 电解 5~7 年干涸风险；**待机 5V 电路关机也在跑，这里用固态尤其关键** |

### 15.4 线材：铜包铝是常态，但要分清「达标」和「虚标」

- 百元档几乎全是**铜包铝**，纯铜要上到 ¥159+（如玄武 500 旗舰）
- **关键不是铜/铝，是线径是否达标**：34 支 ×0.18mm 达 20AWG 就没问题；**标 18AWG 实为 20AWG 就是虚标**（玄武 500K 老批次实锤，官方已改）
- 长期风险：铜包铝氧化发脆是 **5~7 年后**的事，短期不影响

### 15.5 实测算据怎么读（有仪测的优先）

**优先找有第三方仪测视频的型号**（效率 / 纹波 / PF 三档负载），比任何"用料看着不错"都硬：

| 指标 | 合格线（白牌 500W 档） | 实测参考（YG500 Pro ¥99） |
|---|---|---|
| 转换效率 20/50/100% | 白牌约 80%+ | **84 / 85 / 80%** |
| PF 值 | 主动式应 >0.9 | **0.98 / 0.98 / 1.00** |
| 12V 纹波 | <120mV 国标 | **45.3 / 56.5 / 75.5 mV**（轻载极品、中满载优秀） |

> 注意：**有仪测数据的低价电源，可能比「用料更好但没数据」的更值得买**——因为数据能被证伪，用料描述不能。

### 15.6 危险信号（见到直接放弃）

1. **AC 输入线没有地线**（「虚空地线」）—— 机箱漏电流无处泄放、摸机箱麻手、静电打坏 I/O、共模 EMI 失效。**这比线径虚标严重一个量级。**
2. **包装/宣传"鼓励过载"**（拉高 OPP 让电源扛着不保护）
3. 只标「峰值 XXX W」不标额定
4. 铭牌参数页拍不出来 / 卖家回避
5. 45–75 元的「全新」—— 全是二手拆机

**地线自测**（10 秒）：万用表一头插 AC 线插头**第三脚（地脚）**，另一头碰电源金属外壳，**应该导通**。不导通直接退。

### 15.7 「以换代修」是电源最实在的保修形态

电源坏了**从来没人真去修**，都是换。所以：

- **3 年以换代修** > 5 年质保（如果后者流程繁琐）
- 但要看细则：**双向运费谁出**（¥99 的电源寄回去运费 20 就失去意义）、是否要求保留原包装、是店铺保还是品牌全国联保
- **下单后立刻截图商品页**（含保修承诺那行字 + 店铺名 + 商品 ID）—— 店铺话术会改，截图不会

### 15.8 瓦数怎么定

```
所需瓦数 ≈ (CPU PPT + 显卡 TGP + 其它 30~50W) × 2
```

- 实测参考：R5 3600（88W PPT）+ RX6500XT（107W）+ 其它 ≈ **250W 满载** → **500W 是最优区间**（40~60% 负载效率最高、风扇最静）
- **不要买 400W 以下**（不是功率不够，是这个档位只有杂牌）
- **不要买 700W+**（这套配置用不上，纯浪费）
- 留余量是给**升级显卡**用的：换 RX6600（132W）→ 280W，500W 照样够

### 15.9 一句话决策

> **电源是唯一"坏一件烧全机"的件。** 同系列里，多花 20~40 元买「同步整流 + 继电器 + 日系主电容 + 长质保」的那一档，是整套配置里性价比最高的一笔——比内存时序、机箱颜值都值。

## 16. 显卡驱动生命周期（比性能更硬的判据）

**买二手卡时，性能之外必须单列一行「支持状态」。** 旗舰老卡光栅可能仍强过新品，但驱动一 EOL 就断崖。

### 16.1 NVIDIA 的 EOL 时间线（官方公告，2025-07-31）

> 原文：「After 11 years of Game Ready Driver support for Maxwell-series GPUs, and 9 years of support for Pascal and Volta-series GPUs, these GPUs will only receive driver updates for **critical security items** beginning **October 2025** and continuing through October 2028. **Game Ready Driver updates, including performance enhancements, new features, and bug fixes**, will be available for systems utilizing Turing, Ampere, Ada, and Blackwell-series GPUs.」

| 架构 | 代表型号 | 状态 |
|---|---|---|
| **Maxwell** | **GTX TITAN X** / 980 Ti / 980 / 970 / 960 / 950 / 750 Ti | ❌ **2025-10 起只剩安全更新** |
| **Pascal** | TITAN Xp / TITAN X Pascal / 1080 Ti / 1080 / 1070 / 1060 / 1050 | ❌ 同上 |
| **Volta** | TITAN V | ❌ 同上 |
| **Turing** 及以后 | GTX 16 系 / RTX 20 系 / 30 系 / 40 系 / 50 系 | ✅ Game Ready 正常 |

实测：2026-01 发布的 582.28 已是纯安全驱动，release notes 里「Fixed Gaming Bugs」一栏为空。

**实际影响**：新游戏不针对它调优；光追、DX12 Ultimate 完整特性、DLSS 均不可用（Maxwell 连 DLSS 都不支持）。

### 16.2 同代对比的正确姿势

**别只看"谁强"，要看"在什么条件下强"：**

| | GTX TITAN X 12G（2015） | RX 6500XT 4G（2022） |
|---|---|---|
| 显存 / 位宽 | **12G / 384-bit（336 GB/s）** | 4G / 64-bit（144 GB/s） |
| 光栅性能 | 约 GTX 1660 Ti 档 | 约 GTX 1650S +5~10% |
| 功耗 | **250W（8+6pin）** | **107W（单6pin）** |
| 驱动 | ❌ 已 EOL | ✅ 持续更新 |
| 矿卡率 | 高（2017 / 2021 两波都赶上） | 极低（4G 小显存 + ×4 通道，没人拿它挖） |
| 光追 / DLSS | ❌ | ❌（RX6500XT 光追基本不可用） |

**结论**：显存不吃紧时老旗舰强 15~35%；**一旦超 4G 显存（现在 3A 高画质很容易超），新入门卡直接崩**。所以：
- **网游 → 新卡**（驱动新、功耗低、帧数够）
- **3A 大显存 / 老游戏 → 老旗舰**（但别指望新作优化）

### 16.3 PCIe 代际要配对，别双输

| 卡 | 原生通道 | 配 PCIe 3.0 主板（B350/B450/A520） | 配 PCIe 4.0 主板（B550） |
|---|---|---|---|
| RX6500XT / 6400 | PCIe 4.0 **×4** | ❌ 掉 **5~10%** | ✅ 满速 |
| RX6600 | PCIe 4.0 **×8** | ≈0~2%，基本无感 | ✅ |
| GTX TITAN X | PCIe 3.0 **×16** | ✅ 原生 | ✅ 向下兼容，无损失 |

**反向优化（双输）**：把 ×4 卡插 3.0 板、把 3.0 卡插 4.0 板 —— 前者掉性能，后者零收益还浪费平台。

### 16.4 一句话

> **"二手件的'新'不等于'强'，'强'不等于'能用'。"** 老旗舰的性能优势只在特定场景成立，而驱动 EOL 是全局性的。推荐清单里性能、支持状态、PCIe 匹配三行都要有。

## 17. 垃圾佬替补方案（矿卡 / 魔改卡）—— 默认全部作废

### 17.1 ⚠️ 使用门禁（最重要的一节，先读这个）

**默认状态：本节全部内容作废，不进入任何推荐清单。**

只有在**同时满足**以下条件时才启用：

1. 用户**明确表达**要「性价比方案 / 垃圾佬 / 极限压预算 / 能跑就行」，**或**
2. 用户**主动要求压某个具体配件的预算**（"显卡能不能再便宜点""预算只剩 XXX"）

**且必须做到：**

| 要求 | 说明 |
|---|---|
| **主方案仍以 B站最新装机视频为准** | 先看近期（3 个月内）的装机视频拿配置单，**再**用矿卡/魔改卡做"替补降级选项"。理由：硬件行情和型号迭代快，知识库容易老旧，B站视频是时效性最强的锚 |
| **替补方案单独成段，不和主方案混排** | 标题写明「如果你要压到 XXX 元」，绝不写进主推表格 |
| **每张卡必须标风险等级和验证动作** | 见 §17.4 |
| **绝不作为"升级"建议** | 只能是"降级省钱"选项 |

**默认输出形态**：
```
主方案（B站视频口径）→ 三档预算（省 / 值 / 上限）
替补方案（可选，仅在用户要求压预算时出现）→ 明确标注"二手矿卡/魔改卡，风险自担"
```

### 17.2 矿卡清单（用户点名的这些）

> 这些卡在 §4 的四梯度分级里已有定位，此处补充**实际选型时的取舍**。

| 卡 | 显存/位宽 | 性能档位 | 风险 | 备注 |
|---|---|---|---|---|
| **RX 460 / 470 / 480** | 4G / 128-256bit | 470D 级起 | **必矿**（第一梯度） | 老卡，矿不矿已无意义，只看物理状态；470/480 现在基本只能当亮机/低画质 |
| **RX 570 / 580** | 4G/8G / 256bit | 约 GTX 1060 档 | **必矿** | 存量最大、最便宜；**580 8G 是 2000 元档视频里的常客**（图吧渝小二那台 1670 元方案就用它） |
| **RX VEGA 56 / 64** | 8G **HBM2** / 2048bit | 56≈1070Ti，64≈1080 | **必矿** | HBM2 带宽极高（410-484 GB/s），**大显存优势明显**；但功耗 210-295W、发热大、驱动已进 legacy；**HBM2 一旦损坏不可修** |
| **RX 5600XT / 5700** | 6G/8G / 192-256bit | 5600XT≈2060，5700≈2060S | **高概率**（第二梯度 6700 以下但同代） | RDNA1，**没有光追**；5700 系列有历史驱动不稳问题；性价比常年很高 |
| **GTX 10 系（1060 6G 及以上）** | 6G / 192bit | 1060 6G≈480 | **高概率** | 存量巨大、价格透明；**1060 6G 是矿卡重灾区**，5G/3G 版本矿率低但性能弱 |
| **RTX 30 系** | 8-24G | 3060≈2060S+ | **小概率**（3060+ 除 3080）/ **高概率**（3080） | **LHR 锁算力版挖矿亏本，GPU-Z 可看，无风险**；3080 是重灾区；30 系仍在驱动支持期内（Turing 及以后） |

**选型优先级（同预算下）**：
```
30系 LHR（有锁、驱动在支持期）
  > RX 5600XT / 5700（RDNA1、性能密度高）
  > GTX 1060 6G（存量最大、价格透明）
  > RX 580 8G（最便宜、但必矿）
  > VEGA 56/64（HBM2 大带宽但功耗高、损坏不可修）
  > RX 470/480/460（太老，只适合亮机）
```

### 17.3 魔改卡清单

**共同前提（缺一不可）**：
- **必须配带核显的 CPU**（Intel 带核显型号 / AMD APU），卡本身无显示输出
- **主板 BIOS 要能设「核显优先输出」**，且能关 Secure Boot
- **驱动是魔改版**，不能用官方最新驱动
- **Win10 1803+ / Win11** 才有原生多 GPU 调度

| 型号 | 核心 | 显存 | 性能对标 | 功耗 | 关键限制 |
|---|---|---|---|---|---|
| **P106-90** | GP106 | **3G** GDDR5 | 约 1050 Ti 档 | 75W | 驱动停在 **417.22（2018-12）**，之后官方封堵 |
| **P106-100** | GP106 | **6G** GDDR5 | 约 GTX 1060 6G 的 70-80% | 120W | 同上；**性价比之王，常低于 100 元** |
| **CMP 30HX** | TU116-100 | 6G GDDR6 / 192bit | **约 GTX 1660** | 125W / 1×8pin | PCIe 被锁 **1.1 x16（≈3.0 x4 带宽）**；**补 24 颗 0402 220nF 电容可恢复 x16**；砍编解码 |
| **CMP 40HX** | TU106-100 | 8G GDDR6 / 256bit | **约 RTX 2060S** | 185W / 1×8pin | 同上；**罕见保留了编解码**；实测约 ¥450，性价比偏低（同价能买 5600XT） |
| **CMP 50HX** | TU102-100 | 10G GDDR6 | 规格近 2080 Ti 但**实际远不如** | 250W / 2×8pin | **补电容也恢复不了 x16**（NVIDIA 底层屏蔽），实测性能差强人意 |
| **CMP 90HX** | GA102-100 | 10G GDDR6X | 规格近 3080 | 320W / 2×8pin | 同上，且价格高 |
| **Tesla V100** | GV100 | 16G/32G **HBM2** | 计算卡，游戏性能差 | 250-300W | **无风扇（被动散热）**，需自建风道；**无显示输出**；驱动要 Tesla 版；**只适合算力/AI，不适合游戏** |
| **移动端魔改卡**（如 2060M / 3070M 焊到桌面 PCB） | 笔记本 GPU die | 6-8G | 对应移动版性能 | 视型号 | **无官方驱动支持**，靠改 VBIOS + 魔改驱动；散热与供电是自定义 PCB，质量参差；**二手几乎没有售后** |

**魔改卡的真实取舍（引用实测结论）**：
- **30HX 有性价比**（"P106 Plus 版"），2K 以下能跑；**40HX 性价比偏低**——同价位 RX 5600XT 更强，正经卡还省心
- **半精度性能被砍**（30HX/40HX/P106 都是）→ **不适合 AI 绘图**
- **PCIe 1.1 x16 ≈ 3.0 x4 带宽**，是这类卡的游戏性能天花板；补电容能解决 30HX/40HX，解决不了 50HX/90HX
- 矿卡年份短是优势：30HX/40HX 多为 **2021 年 5-6 月**出厂，实际只跑 1 年出头，清灰换硅脂后剩余寿命可观

### 17.4 替补方案的必做验证动作

**矿卡**（同 §4.3，重点重复三条）：
1. **核心/显存区电容与焊脚是否发黄**（大汗脚，洗不掉）
2. **标签是否非公包**（不写品牌不写系列的涡轮卡 → pass）
3. **是否水洗**（全卡干净但角落脏 → pass）
4. 要 **FurMark 温度 + GPU-Z + SN**

**魔改卡额外三项**：
1. **核显能不能用**（你的 CPU 有没有核显？没有就直接排除魔改卡）
2. **驱动版本**（P106 必须 417.22；30HX/40HX 要问卖家给的是哪版魔改驱动）
3. **补电容是否已做**（30HX/40HX 问"补过电容没有"，成品比裸卡贵但省事）

### 17.5 什么情况下**不该**用替补方案

| 场景 | 原因 |
|---|---|
| 用户要**稳定日用/办公/给家人用** | 矿卡+魔改卡的故障率不可控，售后为零 |
| 用户**不会折腾**（不会刷 BIOS、不会装魔改驱动） | 魔改卡的门槛在软件，不在硬件 |
| 用户 CPU **没有核显** | 魔改卡直接不可用 |
| 用户要**玩新 3A** | 矿卡多为老架构，新作优化差；且 VEGA/580 等已过驱动黄金期 |
| 预算**够买正经二手卡** | 例如 ¥450 的 40HX vs 同价 5600XT —— 正经卡永远优先 |

### 17.6 一句话

> **替补方案的价值是"把预算压到极限"，不是"更划算"。** 同样的钱，正经二手卡通常更省心、更好出手、驱动支持更久。所以它只能在用户**明确要求压预算**时出现，且必须单独成段、标明风险、给出验证动作 —— **默认状态下，这一节全部作废。**
